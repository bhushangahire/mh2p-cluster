# Copy to gal_env.txt (next to Update/) to pass settings to the Android Auto
# hook. One GAL_CLUSTER_NAME=value per line, no spaces; '#' starts a comment.
# install.sh copies the valid lines to /mnt/app/eso/bin/apps/cluster/gal_env
# and the gal wrapper exports them before starting gal.real. Remove the
# file and re-run the installer to clear them. Values win over diag mode.
#
# Live logging without diagnostic mode (/tmp/gal_cluster.log, RAM):
#GAL_CLUSTER_LOG=1
#GAL_CLUSTER_LOG_DETAILS=1
#
# GAL_CLUSTER_INSET_TOP/BOTTOM/LEFT/RIGHT are read by the hook but never
# reach the phone (the hook sends a fixed cluster entry; found on a Q7, PR
# #11, confirmed in the v0034 source and binary). The margins and insets the
# phone honours are built into that entry by modkit/template/template.txt
# when the package is built; see the README's "Fitting the map" section.
#
# The stream size asked from the phone (480, 720 or 1080); the e-tron uses
# 1080 so the 1920-wide frame maps 1:1 onto the panel.
#GAL_CLUSTER_RES=1080
